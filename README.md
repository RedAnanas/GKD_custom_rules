个人使用的 GKD 远程订阅，包含 7 个应用、9 个独立规则组和 11 条规则。

## 添加订阅

在 GKD 的订阅页面添加以下地址：

```text
https://raw.githubusercontent.com/RedAnanas/GKD_custom_rules/main/gkd.json5
```

确认远程订阅正常后，禁用本地订阅中的相同规则组，避免重复匹配。

## 维护

直接编辑根目录的 `gkd.json5`。该文件使用标准 JSON 语法，兼容 GKD 的 JSON5 订阅格式。

- 每次发布修改时，将订阅顶层的整数 `version` 加 1。
- 保持订阅 `id`、已有规则组的 `key` 和已有规则的 `key` 不变。
- 同一应用的多个规则组放在同一个 `groups` 数组中，每组对应一个开关。
- 文件提交并推送到 `main` 后，在 GKD 中刷新订阅。
